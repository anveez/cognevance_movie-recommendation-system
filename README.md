# Movie Recommendation System

A Movie Recommendation System developed as part of my internship at **Cognevance Technologies**.

## Project Overview

This project uses Python and user-based collaborative filtering to recommend movies based on user rating patterns and similarities.

## Features

- Movie ratings dataset preprocessing
- Exploratory Data Analysis (EDA)
- Movie rating distribution analysis
- Popular and top-rated movie analysis
- Genre-based analysis
- User-based collaborative filtering
- Cosine similarity
- Personalized movie recommendations
- Data visualizations

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

RMSE: **0.873**

## Output

Recommendations are saved in `outputs/recommendations.csv`.

Seven visualizations are available in the `charts/` folder.

## How to Run

Install dependencies:

```bash
pip install -r requirements.txt
```

Run:

```bash
python src/main.py
```
